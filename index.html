🎩 The ranking-coach reality check

SEO is improvement, not a promise. Neither a paid ranking coach, an SEO agency, an AI tool nor this free course can guarantee first place (or any particular position) on Google. Search rankings depend on the query, competition, location, search systems and many other factors. Anyone promising guaranteed #1 rankings deserves a very sceptical eyebrow.

Think of SEO as making Cat Shit Candles easier to find and more helpful once customers arrive — not paying someone to bribe the librarian. Paid tools can save time, but the fundamentals are learnable using free tools and your website builder.

🧭 Find the setting, whatever your builder calls it

Look for Pages, Page settings, SEO, Search appearance, or Search engine listing. You may be able to edit page titles, descriptions, headings, text, image descriptions and links yourself. If you cannot find something, ask your provider where it lives—do not assume you have WordPress access just because a page uses wp-content.

Usually in your control: helpful page content, page titles, headings, links and image descriptions. Sometimes provider-controlled: sitemap, robots.txt, redirects, structured data, site-wide speed settings and verification methods. Check independently: indexing, speed, accessibility and search performance using the free tools below.

🖨️ Take the checklist home

A one-page-friendly printable checklist with setup tasks and monthly habits.

My beginner SEO checklist

First-time setup

  • ☐ Explain clearly what the site offers and who it helps
  • ☐ Identify a main search phrase and intent for each key page
  • ☐ Write distinct descriptive page titles and natural headings
  • ☐ Write useful descriptions and clear, readable page content
  • ☐ Use simple URLs and helpful internal links
  • ☐ Check pages are published and allowed to be indexed
  • ☐ Test mobile layout, navigation and buttons
  • ☐ Compress oversized images and add useful alt text
  • ☐ Fix broken links and check accessibility and readability
  • ☐ Set up Google Search Console where possible
  • ☐ Set up a Google Business Profile if eligible

Monthly check-in

  • ☐ Review Search Console clicks, impressions, queries and indexing
  • ☐ Improve one page using actual customer questions
  • ☐ Check mobile speed and usability after major changes
  • ☐ Update genuinely outdated information
  • ☐ Look for one legitimate local partnership or mention
  • ☐ Record changes and compare trends over time

Remember: no paid ranking coach, agency or course can guarantee a Google position. There is no ideal keyword density or magic SEO score.
